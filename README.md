# HỆ THỐNG ĐẶT LỊCH SÂN CẦU LÔNG

Dự án bài tập lớn môn Phân tích & Thiết kế Hệ thống - Đại học Duy Tân.

## 🛠 DANH SÁCH CÔNG CỤ VÀ CÔNG NGHỆ SỬ DỤNG

### 1. Phân tích & Thiết kế (Design & Analysis)
* **Visual Paradigm / Draw.io:** Thiết kế biểu đồ Use Case, Activity Diagram (Swimlane), Sequence Diagram.
* **Figma:** Thiết kế giao diện UI/UX (Wireframe & Prototype).
* **PowerPoint / Canva:** Soạn thảo slide báo cáo tiến độ.

### 2. Công nghệ Lập trình (Tech Stack)
* **Frontend:** HTML5, CSS3, TailwindCSS, JavaScript (ReactJS).
* **Backend:** Node.js / Laravel (PHP).
* **Database:** MySQL / PostgreSQL.

### 3. Quản lý & Quản trị dự án (Management & Tools)
* **Git & GitHub:** Quản lý phiên bản mã nguồn (Version Control) và phân công công việc.
* **VS Code:** Trình soạn thảo mã nguồn chính (IDE).
